新增可选人物记忆插件，提供当前场景的账号关联、画像、来源证据、模型候选审核、管理员干预与审计回滚。人物资料可动态注入上下文，后台总结不依赖向量检索。

提供管理员可审核的账号关联候选、分页筛选历史和版本确认后归档。身份关联曾改变的提示在画像复核后仍保留，提醒核对可能混同的旧记忆。

提示词注入支持释放注册；模型工具参数不再覆盖真实会话。新增用户消息前置事件，确保人物识别和来源记录先于本轮推理完成。

人物状态和审计改为单条唯一 INSERT 的提交日志，避免 SQLite 共享事务失败撤销其他频道已接受的数据库写入。状态缓存可重放恢复，旧库首次提交保存迁移基线；取消发生在提交派发前，成功落库后保持接受。来源重复不改写证据。

核心公开 beforeUserStimulus v1 与 trustedToolSession v1 能力，人物插件在注册副作用前检测，并将发布核心 peer 下限提高到 3.0.4；旧 3.0.3 明确提示升级，源码联调按能力接受。

核心后台保留期清理改为可重试的独立删除，避免清理事务失败回滚同时接受的人物提交和核心消息。
