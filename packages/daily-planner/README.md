# daily planer

YesImBot 日程规划器

## 安装

前往 Koishi 目录，运行：

```bash
bun add koishi-plugin-yesimbot-extension-daily-planer
```

## 安装依赖

```bash
bun install
```

## 构建

```bash
bun build
```

## 打包

```
bun pack
```

## 记忆来源与日程隔离

默认仅根据所选核心记忆生成日程。需要参考近期事件时，在 `memorySources` 中逐项配置平台、机器人账号、频道、读取身份及是否私聊；只有当前仍允许读取的来源会被采用。日程会向此扩展的所有使用者展示，请只配置适合这些读者共同知晓的来源。

每个扩展配置实例拥有独立日程，重启后使用同一配置入口即可恢复。旧版本只有日期、没有归属的日程会保留，但不会自动归入任何新实例；升级后重新生成即可。若来源权限、历史、人物纠错或核心记忆改变，旧日程会在下次读取时重新生成。生成过程中来源发生变化时，本次生成失败，需要重新执行。
