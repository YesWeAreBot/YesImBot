# 聊天回复管理

管理员可以暂停当前或指定会话的 AI 回复。暂停期间，消息与事件继续进入上下文，其他 Koishi 指令正常使用。指令要求 Koishi 权限等级 3。

## 常用指令

| 指令                                | 效果                                                       |
| ----------------------------------- | ---------------------------------------------------------- |
| `chat.pause`                        | 使用配置中的默认时长暂停当前群聊或私聊；初始默认值为 60 秒 |
| `chat.pause 5m`                     | 暂停当前会话 5 分钟                                        |
| `chat.pause permanent`              | 永久暂停，直到主动解除                                     |
| `chat.pause 5m --allow text,quote`  | 保留文本与引用意愿增益，其他类别被抑制                     |
| `chat.pause 10m --allow at`         | 10 分钟内仅允许 @参与回复判断                              |
| `chat.pause 1m --block text,system` | 1 分钟内抑制普通文本增益和系统事件回复                     |
| `chat.resume`                       | 提前解除当前会话的抑制规则                                 |
| `chat.status`                       | 查看当前会话的生效规则与恢复时间                           |

时长数字按秒计算，也支持 `ms`、`s`、`m`、`h`、`d` 及中文单位，例如 `30秒`、`2分钟`。`permanent`、`forever`、`永久` 均表示永久生效。命令指定的时长只覆盖本次操作，不更改配置默认值。

再次执行 `chat.pause` 会完整替换目标正在生效的规则和截止时间。每次设置规则都会清零意愿并取消旧聊天任务；解除或到期后，从零重新积累意愿，不补发旧回复。已经发出的内容不会撤回。

## 选择目标

不指定目标时使用调用指令的当前会话及当前机器人。指定其他会话时可使用以下选项：

| 选项        | 含义                    |
| ----------- | ----------------------- |
| `-g <ID>`   | 指定群或频道 ID         |
| `-u <ID>`   | 指定私聊用户 ID         |
| `-p <平台>` | 指定平台，例如 `onebot` |
| `-b <账号>` | 指定该平台的机器人账号  |

`-c`、`-t`、`-g`、`-u` 不能同时使用。当前平台默认使用接收命令的机器人。跨平台目标能由唯一规则或唯一机器人确定时，无需 `-b`；存在多个候选时才需要补充机器人账号。

`-c` 未指定平台时，根据该会话已有的生效规则识别平台；没有规则时使用当前平台，多个平台存在同号规则时要求用 `-p` 或 `-t` 明确指定。`-t` 在第一个冒号处分隔平台，保留会话 ID 内部的冒号，例如 `onebot:private:123456`。

```text
chat.pause 5m -g 123456789
chat.resume -u 987654321
chat.pause permanent -p onebot -b 1122334455 -g 123456789
chat.resume -c 123456789
chat.resume -t onebot:123456789
chat.resume -t onebot:123456789 -b 1122334455
chat.status -p onebot -b 1122334455 -u 987654321
```

目标机器人须存在于当前 Koishi 实例中。指定私聊用户时，使用对应适配器提供的真实私聊频道 ID；适配器不支持此能力时，请在目标私聊中执行指令。规则按平台、机器人账号和会话分别保存；修改一个目标不会暂停其他机器人的聊天。

## 回复类别

| 类别         | 含义                     |
| ------------ | ------------------------ |
| `text`       | 普通文本的基础意愿增益   |
| `at`         | @的意愿增益              |
| `quote`      | 引用机器人消息的意愿增益 |
| `direct`     | 私聊消息的意愿增益       |
| `system`     | 系统事件触发             |
| `scheduled`  | 定时任务触发             |
| `background` | 后台任务完成触发         |
| `all`        | 全部类别                 |

`--block` 指定被抑制的类别；`--allow` 指定允许的类别，其余全部抑制。两者不能同时使用。多个类别用逗号分隔，`all` 不能与其他类别混用。

例如 `--allow at` 时，一条消息只要包含 @，就可以按 @ 类别增加意愿值；同一条消息中的文本、引用等被抑制类别不叠加增益。完整消息仍会记录进上下文。允许参与判断不代表每次必定回复。

设置、替换、主动解除和到期自动解除规则都会留下操作记录，下次正常生成回复时可看到这些变化。

`--allow text,quote` 保留普通文本基础增益和引用增益：无引用时只计文本增益，含引用时叠加引用增益；同条消息内被抑制的 @ 或私聊加成不计入。
