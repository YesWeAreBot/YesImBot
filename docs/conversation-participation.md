# 对话参与保持

对话参与保持让机器人成功回复后的短时间内，更容易接住相关的下一条消息。默认关闭，旧配置和原有意愿计算行为保持兼容。

```yaml
participation:
    enabled: true
    durationSeconds: 60
    influence: 0.5
```

| 配置              | 默认值  | 含义                                  |
| ----------------- | ------- | ------------------------------------- |
| `enabled`         | `false` | 是否启用参与保持                      |
| `durationSeconds` | `60`    | 成功回复后的参与窗口，1 秒到 1 天     |
| `influence`       | `0.5`   | 当前消息增益的影响强度，范围为 0 到 1 |

只有成功回复会启动或刷新窗口。消息到达、意愿计算、准备回复和状态查询都不会延长窗口。新的成功回复会更新最近互动的发送者，并重新开始完整窗口。

窗口内，下列消息可以获得参与增益：

- 最近一次成功回复所回应的同一发送者继续发送普通消息。
- 其他发送者明确 @ 机器人自身，或引用机器人自身的消息。
- 私聊消息。

如果消息明确 @ 或引用其他人，且没有通过允许类别邀请机器人，就不增加参与增益。识别邀请时检查实际 @ 目标和引用消息作者；允许响应“任意 @”不代表任意 @ 都在邀请机器人。缺少群号信息的群消息仍按群聊处理。缺少发送者 ID 时，不通过“同一发送者”识别延续；缺少引用作者信息时，也不把引用自动视为引用机器人。

增益乘数为 `1 + influence × remainingRatio`，其中 `remainingRatio` 是窗口剩余时间占完整窗口的比例。默认配置下，参与开始时最多增加 50% 的本条消息增益，30 秒后增加 25%，60 秒时恢复原增益。它作用于当前消息产生的意愿增益，不直接抬高已有意愿，不修改回复成本、意愿上限和回复概率规则，也不保证回复。

回复抑制规则继续过滤原始增益。通过 @、引用和私聊获得的参与信号也要求对应类别获允；同一发送者的普通延续要求文本类别获允。完全抑制不会产生新增益，暂停、恢复和暂停到期时，会同时清除参与状态。TypeSafe 的本条消息调整乘数仍正常生效。

不同平台、机器人账号、群聊和私聊分别管理参与状态。参与状态仅保存在内存中，重启后清空。
