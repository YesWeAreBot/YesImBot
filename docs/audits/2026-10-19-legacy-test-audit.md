## 适用范围与剩余事项

- 轮询状态属于返回的模型切换器；重新获取切换器会重置游标与熔断器。未改成服务级全局负载均衡。
- MCP 修复保证运行时整数验证。核心原生工具 JSON Schema 导出仍会丢失 step/min/max 等约束，不能宣称完整 Schema 往返保真。
- 文件大小检查发生在来源读取后，阻止超限存储与恢复；HTTP 下载仍由当前客户端完整缓冲，未实现流式内存上限。
- 在途资源去重在单个资源服务内协调；未增加跨进程事务或重做多个存储目录共用资源表的设计。
- 自动化验证不替代实际 QQ 适配器、远端模型和浏览器截图的部署实测；本次相关网络边界使用离线夹具或本地服务。
