# 后台工具任务

后台工具任务允许模型在等待搜索、网页读取或图片描述时继续处理会话。功能默认关闭，与“处理新消息的策略”独立；开启后，直接调用工具仍按原有顺序等待，模型可使用专门工具将独立操作提交后台。依赖前一步结果的操作仍须等待该结果。

## 配置

在“执行策略 → 后台工具任务”中配置：

| 配置                     | 行为                                               | 默认值                   |
| ------------------------ | -------------------------------------------------- | ------------------------ |
| 启用                     | 允许模型提交后台任务                               | 关闭                     |
| 允许后台执行的工具       | 勾选模型可提交后台的工具；取消勾选不影响普通调用   | 搜索、网页读取、图片描述 |
| 任务完成处理方式         | 下轮对话读取，或完成后进行正常回复意愿判断         | 下轮读取                 |
| 完成意愿结算单位         | 每任务，或同轮对话提交的全部后台任务结束后统一结算 | 按对话轮次聚合           |
| 成功、失败、取消意愿增量 | 分别设置非负数，可为零和小数                       | 均为 0                   |
| 并发上限                 | 当前插件实例最多同时执行多少后台任务               | 4                        |
| 保留任务上限             | 包括执行中与已结束任务；优先淘汰可清理的旧结果     | 128                      |
| 执行超时                 | 到期请求取消                                       | 120 秒                   |

“同轮对话”包括一次接话周期内的多次心跳，不是单次模型 HTTP 请求。聚合模式等待该周期不再提交任务且全部任务结束后结算一次；混合结果按失败优先、其次取消、否则成功分类。容量已满且没有可淘汰记录时，新提交会明确失败，不自动重试。

意愿增量遵循既有上限与衰减，不重新计算来源消息的 @、引用、关键词或私聊加成。启用话题意愿时，会话增量只传递给下一次当前话题判断一次。完成后的回复仍受意愿判断、回复暂停、禁言和会话授权限制。

## 模型工具

- `background_task_start`：指定 `tool` 和 `params`，返回任务 ID；仅接受明确声明支持后台执行的工具。
- `background_task_query`：提供 `id` 读取状态及结果；省略 `id` 列出最近任务与可提交后台的工具名称。
- `background_task_cancel`：指定 `id` 请求取消。模型结合当前用户要求和提示词决定是否调用。

默认勾选 `web_search`、`fetch_webpage`、`get_image_description`，以各工具当前可用条件为准。可在复选列表中取消勾选或全部取消；新加载的第三方工具需要手动勾选。只有声明支持后台执行且已被勾选的工具才能提交后台。运行中撤销后台权限后，该任务不会再向会话提交结果或完成意愿。发送消息、修改配置及身份关联等工具不自动加入。第三方扩展可通过 `ToolMetadata.background` 或 `ToolDefinition.background` 显式声明支持；该声明仅适用于独立操作，不能替代每次调用的数据依赖判断。

每次构建模型上下文会提供当前会话最近 8 项任务快照。快照只含状态、工具名称、时间及有长度限制的真实进度，不包含完整结果；完整结果需查询，过长结果继续使用分页读取工具。自定义提示词模板也会收到转义后的任务快照。结果与进度属于观察数据，不能视为系统指令。

## 管理与取消

需要权限等级 3，在任务所属会话执行：

```text
tool.tasks
tool.tasks <任务ID>
tool.tasks.cancel <任务ID>
```

任务状态包括执行中、取消中、成功、失败、已取消。“取消中”表示取消请求已发出，外部操作尚未确认结束。支持取消信号的工具会尽快退出；无法中止的外部请求仍占用并发位置，直至实际结束，其迟到结果不会恢复已取消任务。取消不能撤销已经发生的外部操作。

后台工具使用独立于前台回复的取消状态，不直接发送会话消息。任务完成后由当前会话接收结果并决定后续回复。历史清除、会话授权撤销、工具停用与插件停止会使相关结果失效；其他会话、机器人或插件实例不能读取或取消这些任务。

任务仅保存在当前进程内。插件重载或进程退出后不恢复、不重放任务；应在外部服务侧核实无法撤销操作的最终状态。
