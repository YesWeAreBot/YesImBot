# 回复决策查询

在需要查看的群聊或私聊中执行 `chat.decision`。该指令需要管理员权限（Koishi authority 3）。

查询内容包括当前意愿、对话参与状态、回复抑制、禁言和任务状态，以及最近一条消息实际经历的意愿增益、阈值、概率、随机数、语义判断和调度结果。成功发送、没有发送、被新消息替代、等待安静期或被暂停，都有对应状态。

查询读取已经发生的结果，不增加意愿、不重新抽随机数、不请求模型、不刷新参与时限，也不触发暂停规则的到期清理。当前版本没有启用回复不应期，查询会明确显示这一点。

每个平台、机器人账号和会话分别记录。较旧任务完成时，不会覆盖后续消息的查询结果。最近记录保存在内存中，最多保留 1000 条消息决策；重启后重新开始记录。没有记录时会显示提示。

语义判断关闭、绕过、超时或被取消时，会说明状态。语义评分和增益乘数只显示当时已有结果；“仅记录”模式的语义乘数不会参与实际意愿计算。

查询不显示消息正文、提示词或请求凭据。`chat.decision` 与 `chat.status` 可以配合使用：前者解释最近决策，后者查看回复抑制规则。
